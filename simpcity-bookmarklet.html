Pong Scrape

This is the browser-only SimpCity scraper. It stores nothing and returns directly to Pong.

One-time setup: bookmark this page, edit that bookmark, name it Pong Scrape, and replace its address with the copied code below.

Pong Scrape

Then open SimpCity in an Incognito tab, log in, open the desired thread, type Pong Scrape in Chrome’s address bar, and select the bookmark. Tap the Scrape button that appears.

Websites cannot create Incognito tabs automatically. Start Pong or SimpCity from an Incognito tab when you want Chrome to erase that session on close.
